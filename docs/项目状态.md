# Authright_Voting 项目状态

更新日期：2026-09-26

适用范围：本地实现与 2026-09-26 的 AWS 生产发布记录；未完成的验收单独列出。

## 当前结论

面向约 30–40 人活动的核心流程已经写入应用：任何人可创建限时单选投票，生成公开投票链接和私密结果管理链接；参与者匿名投票后查看当前结果，结束后所有人查看最终结果；管理员可查询历史和管理所有活动。当前已在 AWS Lightsail 运行，正式网址为 https://vote.authright.com；手机端时间框和装饰箭头修复已上线，真实手机上的完整回归仍待完成。

## 已实现

| 范围 | 当前行为 |
| --- | --- |
| 创建与发布 | 首页进入创建页；标题、说明、2–8 个选项、立即或预约开始、截止时间；服务端校验和创建请求幂等处理。发布后显示公开投票链接、二维码和私密结果管理链接。 |
| 公开投票 | 单选；服务端按活动时间和关闭状态接收选票；同一匿名浏览器身份对同一活动只计一票。已投者能看当前结果，活动结束后结果向所有人开放。 |
| 发起者管理 | 私密链接兑换单场管理会话；查看票数、占比和趋势；复制公开链接、显示二维码、提前结束。 |
| 管理员后台 | 登录、退出、总览、按标题或编号搜索、状态与归档筛选、分页、单场统计、提前结束、归档与取消归档、重置私密管理链接、查看操作记录，并可在单场详情获取公开分享链接。 |
| 界面 | 采用“Authright_Voting”浅色技术风格；首页仅保留主标题、说明和发起入口，三步说明与品牌、管理员入口组成贴底页尾，其他页面不显示三步说明和管理员入口；投票结束页在标题附近保留一处持续显示的“已结束”提示；手机浏览器向根元素注入属性导致的开发模式 hydration 警告已做根节点兼容处理。 |
| 本地运行 | SQLite 持久化、SQL 迁移、交互式管理员初始化与密码重置、在线数据库备份命令；固定开发端口并自动预热投票接口；配置局域网地址后可生成局域网分享链接。 |

## 已验证与验证边界

2026-09-25 在本地执行 `npm test`：7 项测试通过，覆盖创建幂等、匿名身份重复投票、投票时段、结果权限、管理链接重置、局域网请求与 HTTP 环境下的创建编号。`npm run check`（TypeScript 与 ESLint）和 `npm run build` 通过。首页页尾调整后再次通过检查和构建，并在桌面与 390px 手机视口核对页尾贴底、按钮不被覆盖；在创建页确认三步说明与管理员入口隐藏。浅色技术风格更新后还抽查了投票结果页和管理员登录页。

2026-09-26 发布 `dbbfb30`：GitHub Actions 检查、测试、镜像构建通过；生产应用 healthy，HTTPS、正式域名、管理员登录／退出、10 个页面、二维码及已有结果访问通过；应用容器替换前后业务记录数量一致，SQLite 完整性检查通过。发布前完成数据库备份，保留旧镜像与配置供回退。详见[部署文档](部署文档.md)。

约 40 人并发投票、真实 iPhone／微信浏览器完整流程、整台服务器重启、定时与站外备份、恢复演练仍未在本次发布中验证。

## 当前限制与待办

| 项目 | 状态与下一步 |
| --- | --- |
| 防重复 | 仅识别服务器签发的匿名浏览器 Cookie；换设备、清除 Cookie 等仍可能再次投票。当前没有邮箱或实名验证。 |
| 分享文字 | 复制按钮目前只复制公开 URL；每场投票的聊天分享卡片标题和“题目文字可点击”的体验尚未实现。局域网 `192.168.x.x` 地址也不能作为稳定的公网抓取地址。具体分享方式待确认后再设计。 |
| 公开部署 | 已在 AWS Lightsail 上线；Caddy 提供正式 HTTPS，应用固定到镜像 digest。GitHub Actions 只发布镜像，服务器更新仍需执行部署步骤。 |
| 备份运维 | 备份命令已存在；自动调度、保留清理、站外副本、失败通知及恢复演练待部署时配置。 |
| 管理找回 | 发起者丢失私密链接后由管理员人工核实并重置；尚需确定实际管理员联系渠道。 |
| 移动端复验 | 对最近的浏览器注入属性问题已在根 `<html>` 做定点处理，仍需在报错的手机和微信环境中验证效果。 |
