更新日期：2026-09-25  
状态：已按第四套浅色技术风格更新本地界面；真实手机与微信环境仍待实机复验，详见[项目状态](项目状态.md)。

## 1. 方向与参考

选定第四套方案：**浅色系统实验室**。视觉关键词是沉稳、清晰、精确。页面采用浅灰白背景、深色文字、克制的钴蓝强调与细边框；信息层级和留白承担主要引导作用。

已确认的第四版概念图位于本次设计会话中；本文记录落地后的样式规则。正式品牌为**Authright_Voting**。概念图中的图片、数字和投票内容仅用于展示风格；网站沿用原有文案、页面信息和业务流程。

## 2. 色彩

| 用途 | 色值 | 使用方式 |
| --- | --- | --- |
| 页面底色 | `#F3F6F9` | 全站的浅灰白背景 |
| 主文字 | `#20344F` | 标题、正文和重要数字 |
| 主操作强调 | `#3267B1` | 主按钮、链接、进度和选中状态 |
| 次级文字 | `#60738D` | 说明、辅助信息和表头 |
| 内容底色 | `#FFFFFF` | 卡片、表单、投票选项 |
| 结构线 | `#D9E3EF` / `#BDD0E5` | 卡片、输入框和分隔线 |
| 浅蓝强调 | `#E9F2FD` | 标签、选择背景和局部提示 |
| 错误与警示 | `#A6434C` / `#FFF5F6` | 错误边界与浅红底，配合中文文字说明 |

主要操作使用白字钴蓝底。状态与错误仍有文字说明，不能只依赖颜色传递含义。各颜色在组件中的实际组合需按最终字号检查对比度。

## 3. 排版与图形

- 标题使用清晰的无衬线字体；中文优先系统黑体。标题可断成两行，文字仍需随容器宽度自然换行。
- 正文保持清楚易读；英文小标签和编号可使用较宽字距。
- 卡片、输入框和按钮采用细边框与小圆角。主要卡片可用很轻的柔和阴影，不使用硬阴影。
- 少量同心线或网格可用于背景装饰，不遮挡文字、按钮或表单。
- 选中和错误状态仍需文字、勾选或图标表达。
- 不使用持续闪烁。悬停或选中可短距离移动；减少动画偏好时停用位移。

## 4. 关键组件

| 组件 | 样式与行为 |
| --- | --- |
| 顶部标识 | 左侧使用“Authright_Voting”；右侧可显示活动编号或入口，手机上不占据过高空间 |
| 状态贴片 | 浅蓝或浅绿底色加细边框，写明状态；结束状态在标题附近保留一处清晰的“已结束”提示 |
| 倒计时 | 细线分隔的紧凑信息行；临近结束时可强调时间数字，避免持续动画 |
| 选项卡片 | 白底、浅灰蓝细边框和小圆角；整张卡片可点击，至少约 44 × 44 像素 |
| 已选选项 | 浅蓝底色和钴蓝边界，并出现明确勾选标记 |
| 主按钮 | 钴蓝填充、白字、小圆角；宽度随布局变化，手机上可铺满内容宽度 |
| 次要按钮 | 白底加浅灰蓝边框；用于复制链接、返回、查看历史等操作 |
| 结果条 | 中性底轨与高对比填充，旁边直接标出选项、票数及百分比 |
| 表单输入 | 内容底色、蓝色可见边界与清晰标签；错误消息就近展示 |

## 5. 页面应用

### 5.1 投票页

视觉主角是发起者输入的问题。顺序为：品牌／状态 → 标题与说明 → 截止时间 → 选项 → 确认按钮 → 提交后不可修改提示。投票前不能露出当前票数。提交成功后在同一位置展示感谢反馈和当前结果；活动结束后展示最终结果。

固定提示语沿用现有实现，包括“匿名投票 / 单选”“倒计时”“就选这个！”和“匿名参与 · 提交后不能改票”。结束状态在标题附近只显示一处持续可见的“已结束”提示，不覆盖整页或重复堆叠文案。样稿中与餐饮话题有关的描述属于发起者输入内容，不作为系统固定提示语。

### 5.2 首页与创建页

起始页以一句主标题、简短说明和醒目的“发起投票”按钮为中心，不再展示占据半屏的示例投票卡片。三步使用说明与品牌、管理员入口归入首页页尾；内容较少时页尾贴住屏幕底部，窄屏内容较长时则自然排在内容后，不覆盖按钮。右上角入口及实际投票按钮不用指向右上角的箭头。管理员入口仅在首页页脚显示。创建页沿用大标题、浅灰白页面底色和细结构线。表单按“标题与说明 → 选项 → 时间 → 发布”分组；增加或删除选项使用紧凑的次要按钮。发布前显示规则提醒，发布成功后明显区分“投票链接”和“我的结果链接（私密）”。

### 5.3 发起者管理页

保留清晰的活动标题和状态贴片。统计使用清晰的大数字、票数条和趋势图；分享操作集中放在结果附近。提前结束按钮与普通分享操作保持视觉层级区别，并在确认对话框中再次写明影响。

### 5.4 管理员后台

顶部导航、状态标签和主操作延续浅色钴蓝配色。活动列表以可扫描、可筛选为先，少用大面积装饰图形。移动端表格可横向滚动，保留搜索、状态、票数和进入详情的入口。管理链接重置等操作采用清楚的二次确认。

## 6. 响应式与易用性

- 先保证约 320 像素宽度的手机屏幕可完整阅读，桌面上控制内容最大宽度。
- 手机页面选项和主按钮保持足够的点击面积；按钮文字能自然换行或调整内边距。
- 键盘聚焦边框始终可见；提示不只依靠颜色。
- 标题、选项、错误信息和结果数字分别检查浅色背景上的对比度。
- 所有功能性文字使用简体中文；英文字母和编号只作为少量视觉点缀。

## 7. 文案使用约定

品牌名称固定为“Authright_Voting”。投票标题、说明和选项由发起者输入，样稿中的餐饮内容仅用于演示。现有页面文案保持不变；没有出现在样稿中的页面文案可在页面细化时确定。业务规则文案须准确：匿名防重复只针对同一浏览器身份，页面不得宣传为严格的“一人一票”。
